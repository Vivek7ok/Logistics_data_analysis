#### Project Summary



##### Objective



The main goal of this project was to analyze logistics and supply chain operations to identify factors affecting delivery performance, shipping costs, customer satisfaction, and overall operational efficiency. Based on the findings, I provided actionable recommendations to improve logistics performance and support data-driven decision-making.



##### Steps Taken



* Collected and organized logistics data from multiple CSV files.
* Cleaned and transformed the data using Python (Pandas \& NumPy).
* Loaded the processed data into PostgreSQL and designed a relational database schema.
* Used SQL to answer business questions and uncover key operational insights.
* Built an interactive Power BI dashboard to visualize KPIs, trends, and performance metrics.
* Shared recommendations to optimize delivery operations, reduce costs, and improve customer satisfaction.
